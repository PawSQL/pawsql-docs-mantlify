PawSQL 是面向开发者、QA 团队、DBA 与企业数据库团队的 **SQL 工程与治理平台**。

它提供覆盖 SQL 全生命周期的一整套能力：从开发期审核与优化，到发布前质量门禁、生产慢 SQL 治理、性能验证与持续的 SQL 治理。

PawSQL 能力分为五个领域：

- **SQL 质量** — 发现语法、规范、风险与潜在性能问题
- **SQL 优化** — 自动重写 SQL、推荐索引并针对数据库专项负载做优化
- **性能智能** — 借助执行计划、代价与数据库优化器验证改进效果
- **SQL 治理** — 在 CI/CD、生产与企业流程中落地 SQL 质量与性能控制
- **平台与集成** — 将 PawSQL 接入 IDE、CI/CD、API、Webhook、MCP 与企业内部平台

---

## 从 SQL 分析到企业级治理

PawSQL 不止回答“这条 SQL 有什么问题？”，

它还能帮助你回答：

- 该 SQL 是否违反编码或运维规范？
- 是否存在语义等价但更高效的写法？
- 是否应该创建或修改索引？
- 优化后的版本是否真的产生更优的执行计划？
- 同样的检查能否在开发与发布流程中被自动执行？

## SQL 质量

在 SQL 进入测试、发布或生产之前发现其中的问题。

PawSQL 通过解析、语义分析、数据库元数据与规则引擎进行结构化分析，而不是仅依赖文本匹配或正则表达式。

### 核心能力

- SQL 语法与兼容性检查
- SQL 编码规范审核
- 高风险 DDL/DML 检测
- 潜在性能问题检测
- 数据库专项规则
- 企业自定义规则
- 存储过程 SQL 分析

### 典型场景

开发者自检、代码评审、发布检查、数据库变更评审与企业 SQL 规范落地。

## SQL 优化

自动发现更高效的 SQL 写法与索引策略。

PawSQL 结合 SQL 解析、语义等价分析、重写规则、索引分析与数据库优化器信息，生成可评估的优化候选。

### 核心能力

- SQL 自动重写
- 子查询优化
- Join 优化
- 谓词下推
- 聚合与排序优化
- 深分页优化
- 智能索引推荐
- 分布式 SQL 优化
- 大数据 SQL 优化

目标不只是给出建议，而是产出可以被评估并应用的优化候选。

## 性能智能

判断一次优化是否真正改善了 SQL。

SQL 优化不应只依赖启发式规则。PawSQL 借助数据库优化器信息、执行计划与代价对比，评估原始 SQL 与优化后 SQL。

### 核心能力

- 优化前后执行计划对比
- SQL 代价对比
- 索引有效性验证
- 执行计划可视化
- 高代价算子检测
- 全表扫描与大结果集操作检测
- 慢 SQL 分析
- 优化收益评估

- 批量 SQL 审核与优化
- SQL 指纹识别
- 慢 SQL 治理
- 数据库迁移 SQL 治理
- SQL 风险分级
- 优化优先级

## PawSQL 的典型使用方式

不同角色可通过不同的工作流进入 PawSQL。

| 角色 | 典型需求 | 推荐能力 |
|---|---|---|
| 开发者 | 编码时发现并优化 SQL | SQL 审核、SQL 重写、IDE 集成 |
| DBA | 规模化治理慢 SQL 与索引问题 | 批量 SQL 治理、索引推荐、性能验证 |

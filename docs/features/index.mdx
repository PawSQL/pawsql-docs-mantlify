# 核心功能

PawSQL 的核心能力围绕"写出更好、更快的 SQL"：

| 能力 | 一句话说明 | 深入 |
|---|---|---|
| 规范审核 | 在上线前按[审核规范](reference/audit-rules/index)检查 SQL/DDL 合规与风险 | [审核规则目录](reference/audit-rules/index) |
| 重写优化 | 语义等价改写查询结构（EXISTS→JOIN、OR→UNION、谓词下推…） | [优化算法目录](reference/optimizer-rules/index) |
| 索引推荐 | 基于查询结构主动设计最优索引，并可做 What-If 验证 | 见 PawSQL Optimizer |
| 性能验证 | 对推荐方案执行真实代价/执行计划验证 | 见 PawSQL Optimizer |
| 执行计划可视化 | 把执行计划渲染为易读结构，定位瓶颈 | PawSQL Plan Visualizer |

各能力面向"人 + 引擎 + CI"三处使用：Web/桌面平台、DBeaver/JetBrains/VS Code 插件、CI/CD 流水线。

# PawSQL API

The API Reference tab is rendered from the repository-local OpenAPI specification at `openapi/pawsql-openapi.yaml`.

Keeping the specification in this repository (instead of a remote URL) means API changes travel through the same Git PR review and drift-detection pipeline as the documentation.

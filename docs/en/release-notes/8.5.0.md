# PawSQL 8.5.0

> Draft release note for the new documentation site. Content is being reconciled with the actual product release.

## SQL Optimization

- **OR to UNION Optimization** — cost-based rewrite that lets OR-ed branches use separate indexes. See the [rule reference](en/reference/optimizer-rules/opt-or-union) and the [user guide](en/user-guide/optimization/or-union).

## SQL Audit

- Audit rule coverage continues to be expanded; rule pages are generated from `metadata/rules/*.yaml` (see [audit rules](en/reference/audit-rules/sql-index-023)).

## Documentation Platform

- Rule / database / configuration reference pages are now generated from metadata and guarded by a documentation gate (Phase 3).

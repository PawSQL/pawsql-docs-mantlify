# Supported Databases

See the [compatibility matrix](/en/reference/compatibility/index) for database-version and capability-specific records.

Support is conditional on the recorded versions and capabilities; it must not be inferred for an entire database family. `unknown` means unverified, not supported or unsupported.

The authoritative source is `metadata/databases/*.yaml`; the matrix is generated from it and must not be edited by hand.

> Draft: the version and capability list is being reconciled with the product team.

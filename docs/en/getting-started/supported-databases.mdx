# Supported Databases

PawSQL targets the following database families:

- **MySQL** (5.7 / 8.0 series)
- **PostgreSQL** (14 / 15 / 16 / 17 / 18)
- **Oracle**
- **SQL Server**
- **openGauss / GaussDB**
- See the [compatibility matrix](en/reference/compatibility/index) for the full per-database, per-version, per-capability table.

The authoritative source is `metadata/databases/*.yaml`; the matrix is generated from it and must not be edited by hand.

> Draft: the version and capability list is being reconciled with the product team.

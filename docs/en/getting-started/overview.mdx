# Overview

PawSQL makes SQL performance optimization automatic and verifiable. Its two core capabilities are:

1. **Semantic query rewrite** - fixing logical structure the optimizer will not touch, without changing query results.
2. **Cost-based index recommendation** - designing the optimal index from the query structure, not just picking from existing indexes.

The two compose: a rewrite changes the query structure, and index recommendation then runs on the rewritten form.

## Capability areas

- **SQL review / audit** - applies audit rules (objects, DDL, DML, indexes, performance) to flag risky or low-quality SQL before it reaches production.
- **Optimization** - rewrites and index recommendations driven by the PawSQL Optimizer engine.
- **Compatibility** - supports MySQL, PostgreSQL, Oracle and other databases and versions tracked in the [compatibility matrix](en/reference/compatibility/index).

## Who uses it

Database administrators, developers and CI pipelines that want SQL quality gates and concrete, explainable optimization suggestions.

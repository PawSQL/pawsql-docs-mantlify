## One product

PawSQL is one product. Cloud denotes public deployment. Engine, Optimizer, Auditor, Advisor and Patroller are components or delivery forms.

## Choose a path

Use Web access to learn the workflow, private deployment when you require services in your own environment, and an IDE integration for development workflows. For an automated release process, start with the [use cases](/en/use-cases/index).

## Environment and interface

Deployment identifies where a service runs. Web, API and IDE identify how you access its capabilities. An IDE integration alone does not determine the service deployment. Consult verified delivery-version instructions for the available combinations.

## Before starting

Confirm database/version compatibility, connectivity, permissions and delivery version. An unknown entry in the [compatibility reference](/en/reference/compatibility/index) is not a support commitment.

## Next steps

Read the [getting started guide](/en/getting-started/quickstart). The current Web walkthrough is available in [Chinese](/user-guide/cloud/quickstart). Detailed installation and integration instructions will be added as verified content becomes available.

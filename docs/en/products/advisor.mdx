# PawSQL Advisor

The advisory layer that reviews SQL and DDL against a rule set and explains how to improve it:

- **Audit rules** grouped by category - objects, DDL, DML, indexes and performance. Each rule reference page states the problem, why it matters, how to fix it, and shows bad/good examples (see the [rule references](en/reference/audit-rules/sql-index-023)).
- **Optimization suggestions** with the estimated impact.
- **What-If validation** against a live database before applying a change.

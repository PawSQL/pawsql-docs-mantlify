# PawSQL Optimizer

The optimization engine for:

- **Cost-based index recommendation** - the optimizer estimates which new index would lower cost for a given workload, and can validate it against a live database.
- **Semantic query rewrite** - structural rewrites such as [OR to UNION](en/reference/optimizer-rules/opt-or-union), EXISTS-to-JOIN and predicate pushdown that preserve results while changing the execution shape.
- **Configuration** - tunable through parameters such as [explain.timeout](en/reference/configuration/explain-timeout).

Supported database and version coverage is tracked in the [compatibility matrix](en/reference/compatibility/index).

# 用户场景

按角色与场景挑选最贴近你的路线。各场景独立成篇，后续将展开为手把手续教程。

| 场景 | 解决什么问题 | 相关入口 |
|---|---|---|
| 开发者：在 IDE 中自助优化 SQL | 写完即审，减少等待 DBA | DBeaver / JetBrains / VS Code 插件 |
| CI/CD：建立 SQL 上线门禁 | 把 SQL 审核放进流水线，不达标不放行 | GitHub Actions / DevOps |
| DBA：批量治理生产慢 SQL | 收敛慢 SQL 清单，逐条给可执行优化 | PawSQL 平台 + 性能巡检（Patroller） |
| 信创 / 数据库迁移中的 SQL 治理 | 换库前的兼容性与规范治理 | [SQL 审核](en/user-guide/sql-audit/index) |
| 企业：统一 SQL Governance 平台 | 集中规则、角色与发布门禁 | 企业版 / 私有化 |

> 草稿占位：各场景的完整教程与截图正在撰写，随内容到达 `published` 后逐步点亮。

## 归因：索引与重写双引擎

针对获得正向优化的 SQL，PawSQL 输出了归因分析。

### 索引优化：贡献超 90%

几乎在所有成功优化的案例中，智能索引推荐都发挥了关键作用。它不止判断「缺什么索引」，还能识别索引的多种加速效应：

- 加速查找：为过滤条件、连接列创建精准索引，全表扫描改为索引扫描
- 避免排序：利用索引有序性，消除 `ORDER BY`、`DISTINCT`、`GROUP BY`、窗口函数引发的文件排序
- 复合索引避免回表：设计覆盖查询所需全部列的复合索引，查询响应从秒级压缩到毫秒级

### SQL 重写优化：约 20% 案例的关键助攻

除索引推荐外，重写优化引擎在约 20% 的案例中独立或联合发挥作用。核心算法包括：

- 消除索引列上的计算：`WHERE func(col) = ?` 或 `col + 1 > ?` 等价改写，恢复索引使用
- 投影下推：执行早期裁剪不必要列
- 谓词下推：过滤条件推至数据源层，提前滤除无效数据
- 标量子查询解关联：标量子查询改为 `JOIN` / `APPLY`，避免逐行反复执行
- Max/Min 重写：`WHERE col = (SELECT MAX(...) ...)` 改为 `ORDER BY + LIMIT 1`，利用索引有序性

# 支持的数据库

请查看[数据库兼容性矩阵](/reference/compatibility/index)，按数据库版本和能力确认适用范围。

状态为 `supported` 表示支持，`partial` 表示存在限制，`unsupported` 表示不支持，`unknown` 表示尚未验证。当前待核实条目不构成产品支持承诺；选择部署方案前应核对实际交付版本。

> 状态：草稿，版本与能力清单待与产品团队核对后定稿。

PawSQL Cloud 由 PawSQL 提供和维护，无需自行准备服务器或部署平台组件。用户通过浏览器登录后，可以创建工作空间并使用账号授权范围内的 SQL 审核和优化能力。

## 目标

通过浏览器访问 PawSQL Cloud，完成登录和首次 SQL 优化、审核或性能巡检。

## 准备工作

需要 PawSQL Cloud 官方访问地址、受支持的浏览器和可用的账号；团队使用时还需组织或项目成员身份。

## 登录 PawSQL Cloud

<Steps>
  <Step title="打开访问地址">
    在浏览器中打开 PawSQL Cloud(https://www.pawsql.com)。
  </Step>
  <Step title="完成登录">
    使用页面提供的登录方式完成身份验证。
  </Step>
</Steps>

<Warning>
只使用 PawSQL 官方提供或企业管理员确认的访问地址。不要在来源不明的页面输入账号、密码或访问令牌。
</Warning>

## 第一次登录后

建议依次完成以下操作：

1. 创建或选择一个测试工作空间。
2. 使用非敏感查询完成第一次 SQL 优化。
3. 需要 IDE、MCP 或 API 时，再创建对应访问凭据。

## Cloud 与本地客户端

IDE 插件、PawSQL MCP 或其他客户端连接 PawSQL Cloud 时，需要使用 Cloud 服务地址和支持的认证方式。Web 登录状态通常不能直接替代客户端认证。

| 客户端 | 通常需要准备 |
| --- | --- |
| Web 控制台 | 登录账号 |
| JetBrains、VS Code、DBeaver | Cloud 服务地址、访问凭据 |
| PawSQL MCP | Cloud 服务地址、MCP 启动配置、访问凭据 |
| OpenAPI | API 地址、访问令牌或其他指定认证信息 |

## 数据与安全

- 提交 SQL 前移除密码、令牌和不必要的业务数据。
- 不要在公共设备中保存登录状态。
- 不再使用的访问令牌应及时吊销。
- 通过数据库连接创建工作空间前，确认网络和安全策略允许连接。
- 企业用户应遵守组织的数据分类和外部服务使用规范。

## 预期结果

登录后进入 Cloud 控制台，可看到账号授权范围内的工作空间与 SQL 优化等能力。

## 验证

登录后确认当前组织、项目与账号正确，并确认工作空间和 SQL 优化功能可见。

## 常见问题

### 无法打开登录页

检查访问地址、网络代理、DNS 和 HTTPS 证书。企业网络存在访问控制时，联系网络管理员确认策略。

### 看不到 SQL 优化或工作空间菜单

检查账号权限、产品版本和用量状态。部分功能可能只对特定角色或授权方案开放。

### 客户端无法复用浏览器登录

IDE、MCP 和 API 可能需要独立的访问凭据。参见[登录与身份认证](/user-guide/installation/authentication)。

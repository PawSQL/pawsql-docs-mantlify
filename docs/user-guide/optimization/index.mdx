PawSQL 整合关系数据库查询优化的最佳实践，通过查询重写优化、智能索引推荐帮助开发人员和 DBA 一站式解决 SQL 性能问题，并记录优化历史供日后查看、跟踪和共享。

## 准备工作

准备一个表、索引和统计信息与实际环境一致的工作空间。

## PawSQL 中的概念

- **工作空间**：进行查询优化的环境，包括表、视图、索引及相关统计信息。
- **工作负载**：要优化和分析的单个或一组 DML SQL 语句。
- **优化任务**：对某个工作空间、针对某组工作负载执行的优化操作，一般包括 SQL 审查、重写优化、索引推荐等。

## 四步完成一次优化

<Steps>
  <Step title="创建工作空间">
    通过数据库连接、上传 DDL 文件或手工输入 DDL 建立工作空间，使表、索引和统计信息贴近真实环境。
  </Step>
  <Step title="输入待优化 SQL">
    从文本框、SQL 文件、数据库日志或 MyBatis Mapper 文件输入待优化的 SQL。
  </Step>
  <Step title="创建优化任务">
    配置基础选项、优化验证、索引推荐策略和优化规则后提交任务。
  </Step>
  <Step title="查看优化结果">
    从摘要进入每条 SQL 的详情，查看重写、审查、索引推荐和性能验证结果，并对比执行计划。
  </Step>
</Steps>

## 选择使用入口

| 入口 | 适用场景 | 特点 |
| --- | --- | --- |
| Web 控制台 | 临时分析、复杂 SQL、完整结果查看 | 功能完整，适合对比和导出 |
| IDE 插件 | 编码阶段即时优化 | 无需离开开发环境 |
| PawSQL MCP | AI 编程助手工作流 | 可在当前开发上下文中调用工具 |
| API | 平台集成、批量调用和自动化 | 适合可重复、可编排流程 |

## 预期结果

完成一次包含 SQL 审查、重写优化和索引推荐的优化任务，结果可供查看、跟踪和共享。

## 验证

依次完成创建工作空间、输入 SQL、创建优化任务、查看结果四步，并确认摘要与详情结果完整。

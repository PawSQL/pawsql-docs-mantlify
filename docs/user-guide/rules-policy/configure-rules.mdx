规则管理页展示审核平台内置的默认规则模板，共 260 条审核规则。它独立于创建审核策略时的「规则配置」步骤：前者用于浏览整套规则目录，后者用于在某个模板内挑选规则。

## 目标

在规则管理页按分类树、级别筛选与搜索浏览内置审核规则，查看每条规则的启用状态、类别、级别、阈值与父级节点。

## 准备工作

无特殊前置条件，只需能够访问审核平台的规则管理页。

## 页面布局

- **左侧**：分类树（大类 → 子类）、级别筛选（提示 / 警告 / 严重 / 未启用）、搜索框；
- **右侧**：规则表格，列为「是否启用 / 规则名称 / 类别 / 级别 / 阈值 / 父级节点」。

## 规则分类

规则按「对象设计」「对象操作」「数据操作」三大类组织，大类下再分子类：

| 大类 | 子类 |
| --- | --- |
| 对象设计 | 命名规范、数据分布、表/视图定义、约束、索引、其他、注释、列定义、字符集/排序规则 |
| 对象操作 | 语法错误、更新对象、删除对象、添加约束 |
| 数据操作 | 性能、可维护性、分布式、正确性、安全性 |

## 定位规则

- **分类树**：点击分类或子类，过滤出该类别下的规则；
- **级别筛选**：按「提示 / 警告 / 严重 / 未启用」筛选；
- **搜索**：在搜索框输入规则名关键字。

## 规则级别

每条审核规则有一个级别，标记该规则检出问题的严重程度，从轻到重为「提示」「警告」「严重」三档。

## 规则表格列

| 列 | 说明 |
| --- | --- |
| 是否启用 | 该规则是否启用 |
| 规则名称 | 规则名称 |
| 类别 | 规则所属类别 |
| 级别 | 规则级别（提示 / 警告 / 严重） |
| 阈值 | 规则参数；命名规范类规则为正则表达式 |
| 父级节点 | 规则所属的父级规则（规则采用层级化设计，子规则细化父规则） |

## 阈值

不同规则的阈值形式不同。命名规范类规则使用正则表达式约束对象名格式：

| 规则 | 默认阈值 |
| --- | --- |
| 表名命名规范 | `^[a-z]+(_[a-z]+)*$` |
| 列名命名规范 | `^[a-z]+(_[a-z]+)*$` |
| 唯一性索引命名规范 | `^uk_{table}_{columns}$` |
| 主键命名规范 | `^pk_{table}_{columns}$` |
| 外键命名规范 | `^fk_{c_table}_{c_columns}_{p_table}_{p_columns}$` |
| 索引命名规范 | `^idx_{table}_{columns}$` |
| 自增列命名规范 | `^id$` |
| 数据库命名规范 | `^[a-z]+(-[a-z]+)*$` |
| 模式命名规范 | `^[a-z]+(-[a-z]+)*$` |

内置默认模板的规则与阈值只读；如需自定义，先基于全局模板创建局部模板（见[审核策略管理](/user-guide/rules-policy/rule-sets)），再在局部模板上启用、禁用或调整规则。

## 验证

点击某个分类或子类、应用级别筛选或搜索规则名，确认右侧规则表格更新为匹配规则，并显示启用状态、类别、级别、阈值与父级节点。

SQL 质量门禁通过审批流配置实现：在「配置 → 审批流」中设置允许创建工单的最高风险等级，系统据此决定审批流程。

  ![审批流配置](/images/rules-policy/quality-gate.png)
</Frame>

## 风险等级

风险等级作用于整个工单，从轻到重分三档：

| 风险等级 | 相对程度 |
| --- | --- |
| 通知 | 最轻 |
| 警告 | 中等 |
| 严重 | 最重 |

「风险等级配置」设置允许创建工单的最高风险等级；工单风险等级高于该值时，需要更严格的审批流程。

## 规则级别与风险等级

「规则级别」与「风险等级」是两个不同维度，不要混淆：

| 维度 | 作用对象 | 值域 |
| --- | --- | --- |
| 规则级别 | 单条规则 | 提示 / 警告 / 严重 |
| 风险等级 | 整个工单 | 通知 / 警告 / 严重 |

规则级别标记单条问题的轻重，见[规则管理](/user-guide/rules-policy/configure-rules)；风险等级决定工单是否需要更严格的审批流程，在本页配置。

## 审批流节点

审批流按以下节点推进：

| 节点 | 说明 |
| --- | --- |
| 风险等级配置 | 设置允许创建工单的最高风险等级 |
| 工单创建 | 系统节点；工单被创建，或工单被驳回后等待修改 SQL 语句 |
| 提交复核 | 工单创建者提交复核，触发审核流程 |
| 审核节点 | 配置审核人；可添加多个审核节点 |
| 执行上线 | 配置执行人，完成工单流程 |

## 配置步骤

审批流配置为多步向导：先配置风险等级，再依次配置提交复核、审核节点与执行上线，最后点击「保存配置」。配置过程中可随时「重置配置」恢复默认。

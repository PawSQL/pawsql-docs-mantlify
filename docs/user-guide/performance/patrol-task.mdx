性能巡检（数据库对象巡检）用巡检模板中的审核规则检查实例内的数据库对象（表），识别结构缺陷、命名不规范、缺少注释等风险。巡检在接入实例向导的「库巡检配置」步骤配置，接入完成后可在数据库对象页手动或定时触发。

## 目标

用巡检模板中的审核规则检查数据库对象，识别结构缺陷、命名不规范、缺少注释等风险。

## 准备工作

慢查询配置已通过，且已有与目标数据库类型匹配的巡检模板。

## 库巡检配置步骤

慢查询配置通过后，向导进入「库巡检配置」。该步骤选择用于巡检的巡检模板（规则集）。

<Frame caption="库巡检配置：选择数据库巡检模板">
  ![库巡检配置](/images/performance/patrol-db-patrol-config.png)
</Frame>

巡检模板决定巡检时启用的审核规则与风险级别。模板按数据库类型提供（如「MySQL数据库巡检模板」），与审核平台的规则模板共享同一套规则体系。

## 手动巡检

接入完成后，在数据库对象页点击「手动巡检」立即触发一次巡检。巡检由服务端执行，完成后页面更新概要数据与对象清单。

<Frame caption="数据库对象页：概要、风险分布与「手动巡检」入口">
  ![数据库对象巡检](/images/performance/patrol-db-objects-data.png)
</Frame>

巡检完成后，概要区展示本次巡检结果（实测示例）：

| 指标 | 示例值 | 说明 |
| --- | --- | --- |
| 巡检模板 | MySQL数据库巡检模板 | 本次巡检使用的规则集 |
| 数据库对象数 | `779` | 巡检覆盖的数据库对象（表）数量 |
| 最新巡检时间 | `2026-09-15 11:19:00` | 最近一次巡检完成时间 |

## 定时巡检

在数据库对象页顶部开启「定时巡检」开关，设置巡检周期（每 N 天）与执行时间（在 HH:MM），点击「更新」保存。开启后平台按计划自动巡检。

## 巡检结果解读

巡检结果按风险级别与规则汇总，详见[巡检任务报告](/user-guide/performance/reports)。

## 提交前检查

- [ ] 巡检模板与目标数据库类型匹配；
- [ ] 巡检模板中启用的规则符合治理目标；
- [ ] 手动巡检完成后概要数据已更新；
- [ ] 定时巡检计划与业务低峰时段错开（如需要）。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 无可选巡检模板 | 数据库类型、模板可见范围 |
| 巡检对象数为 0 | 数据库/模式是否正确、账号是否有读取元数据的权限 |
| 巡检结果与预期不符 | 巡检模板启用的规则、规则阈值 |

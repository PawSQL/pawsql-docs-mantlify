巡检完成后，数据库对象页汇总本次巡检发现，形成可下钻的巡检报告。报告从「概览 + 风险分布 + Top 问题 + 对象清单」四个层次呈现，用于判断实例整体健康度并定位最需要处理的对象。

## 目标

在数据库对象页查看巡检报告，判断实例健康度并定位待处理对象。

## 准备工作

已完成一次巡检，数据库对象页已有巡检发现。

## 操作步骤

自上而下阅读报告：概要概览、风险级别分布、Top 审核规则、Top 数据库对象，最后下钻对象清单。

## 概要

| 指标 | 说明 |
| --- | --- |
| 巡检模板 | 本次巡检使用的规则集（如 MySQL数据库巡检模板） |
| 数据库对象数 | 巡检覆盖的数据库对象（表）数量 |
| 最新巡检时间 | 最近一次巡检完成时间 |

## 风险级别分布

「风险级别」图按「严重 / 警告 / 提示」三档统计巡检发现的总数。实测示例：`4964` 条发现中，严重 `97`、警告 `4800`、提示 `67`。点击某一档可按该风险级别过滤对象清单。

## Top 审核规则

「审核规则」图列出触发次数最多的规则，用于发现共性问题。实测示例中触发最多的规则包括：

| 规则 | 触发次数 |
| --- | --- |
| 主键列需使用指定的数据类型 | `768` |
| 禁止指定列的字符集 | `744` |
| 非空列需指定默认值 | `700` |
| 主键应使用自增列 | `582` |
| 列必须有注释 | `526` |

## Top 数据库对象

「数据库对象」图列出问题最多的对象（表），用于优先定位整改对象。实测示例中，`pawsql_*` 各库的 `sql_audit_task` 表均有 `14` 处问题。

## 对象清单

对象表格按表列出结构信息与巡检结果：

| 列 | 说明 |
| --- | --- |
| 表名 | 数据库对象（表）名称 |
| 数据库/模式 | 表所属的库/模式 |
| 列数 | 表的列数 |
| 行数 | 表的行数 |
| 索引数 | 表的索引数 |
| 巡查异常 | 该表的巡检发现数（如「警告:8」） |
| 创建时间 / 更新时间 | 巡检记录的创建与更新时间 |
| 操作列表 | 下钻查看该表的巡检明细 |

表格上方提供筛选条件：搜索数据库对象、数据库/模式、违反规则，以及「违反规则」「新增」开关，用于只看存在问题的对象或新增对象。

## 预期结果

数据库对象页展示巡检概要、风险级别图、审核规则图、数据库对象图，以及带各表巡查异常的对象清单。

## 验证

确认概要反映最近一次巡检，点击某风险级别或规则能过滤对象清单。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 报告为空 | 是否已完成一次巡检、账号是否有查看权限 |
| 风险级别为 0 | 巡检模板规则是否启用、数据库/模式范围是否正确 |
| 对象数与预期不符 | 数据库/模式选择、账号元数据读取权限 |

审核策略是一组可复用的审核规则及参数配置，在创建审核工单页面的“审核策略”下拉框中选择。PawSQL 按数据库类型内置了默认审核策略（MySQL、Oracle、PostgreSQL、DB2、openGauss、GaussDB、TDSQL、达梦等，每种约百余条启用规则），优化平台与审核平台共享同一套规则配置；通常直接选择与目标数据库匹配的默认策略即可。选择正确的策略，可以让同类 SQL 使用一致标准，并避免将不适用于当前数据库或环境的规则加入结果。

<Note>
本文档统一使用“审核策略”。它在界面中有多个称呼——导航与创建表单显示“审核模板”、模板页创建按钮为“创建规则模板”、个别描述为“审核规则集”，均指同一对象：一组启用的规则及其风险级别、阈值和例外配置。策略的创建、调整和版本管理见[规则与审核策略](/user-guide/rules-policy/)。
</Note>

## 选择原则

按以下顺序确定策略：

1. 匹配目标数据库类型和版本；
2. 匹配环境，例如开发、测试或生产；
3. 匹配审核用途，例如日常开发、上线变更或专项治理；
4. 确认策略归属、可见范围和维护人；
5. 核对规则级别及参数阈值。

## 选择默认策略还是自定义策略

默认策略随数据库类型内置，覆盖该数据库的通用审核规范。组织也可在默认策略基础上，为上线审核、生产治理、迁移检查等专项场景维护自定义策略：

| 策略类型 | 适用场景 | 说明 |
| --- | --- | --- |
| 默认策略 | 常规审核 | 随数据库类型内置，覆盖该数据库的通用规范，约百余条启用规则 |
| 自定义策略 | 上线审核、生产治理、迁移检查等专项场景 | 在默认策略基础上调整启用的规则、风险级别和阈值 |

选择自定义策略时，确认它基于与目标环境一致的数据库类型和版本，并核对启用的规则与阈值是否适用于当前项目。

## 检查策略详情

选择策略前至少检查以下信息：

- 支持的数据库类型和版本；
- 策略状态及最近更新时间；
- 启用和停用的规则；
- 每条规则的风险级别；
- 长度、数量、耗时或影响行数等阈值；
- 规则的例外条件；
- 策略是否属于当前项目或组织。

<Warning>
同名策略可能因项目、版本或更新时间不同而包含不同规则。执行正式审核时，不要只根据名称判断策略是否一致。
</Warning>

规则级别、阈值、例外条件的配置，以及策略的创建和调整，见[规则与审核策略](/user-guide/rules-policy/)。

## 无法选择策略

| 现象 | 处理建议 |
| --- | --- |
| 策略列表为空 | 检查数据库类型、项目、权限和策略状态 |
| 目标策略不可见 | 检查策略可见范围和当前组织 |
| 规则与预期不符 | 核对策略版本、更新时间和数据库版本 |
| 无权修改策略 | 联系项目管理员或策略维护人 |
